# Taxonomy diagnosis — 50 benchmark sample (2026-09-15)

## Frozen sample and limits

Baseline: origin/main 3991c92. 15 targeted high-risk examples, 15 named reference controls, and 20 seeded random paper-source entries (seed 20260915). This is a diagnostic, risk-enriched sample, **not an unbiased estimate of the site-wide error rate**. Abstract/official dataset-page level review, not reproduction or full-paper validation. Sources are recorded per row. Exact version/date is unresolved for AIME; StartupBench tool-use needs protocol review.

## Diagnosis, before implementation

- Programming-language diversity was misread as natural-language multilinguality.
- Temporal reasoning over legal texts, EHRs, waveforms or dated images was misread as video.
- Mentioning sessions/GUI/agents was confused with evaluating persistent memory/computer operation/agent capabilities.
- Some valid task labels were missing. No suitable current label exists for several commonsense or application-performance tasks; do not invent one silently.
- SWE-bench Multilingual points to the Multimodal paper and its summary conflates a different dataset. Source identity must be corrected alongside labels.
- Star-history files retain old direction tags. Rebuilding Library alone cannot fix attention attribution.

## Planned website impact

1. Shared reviewed classification applies to all public records and Library, with source-bearing evidence. Reviewed decisions persist on regeneration. No benchmark records are deleted; unclassified records remain searchable.
2. Radar and Library show the same canonical direction names. Legacy domain/capability axes remain available as explicitly separate filters, not interchangeable direction labels.
3. Trends release aggregation continues to use current Library labels. Repository histories are reassigned from current eligible Library associations and deduplicated by normalized GitHub URL, never stale historic tags. Aider's tool repository is excluded from benchmark-specific attention; its benchmark remains in Library.
4. Counts, direction memberships, and attention rankings can change; raw star events, observation dates and release rankings are not recalculated. A shared repo still measures repository attention, not the marginal popularity of a single benchmark variant.
5. Keep the current published UI. Do not publish the unapproved local Trends redesign. A push to main invokes the existing Pages workflow for the audited data/classification fix.
6. Validate all 50 expected outcomes, public/Library parity, manifest counts, repository direction assignment, pipeline tests and static build; record actual impact below after generation.

## Measured impact after implementation

- Library records: 2855 → 2855; direction assignments changed for 32 entries (27 reviewed sample corrections plus 5 programming-language guard corrections).
- Additional guarded entries: LoopsBench, MacroBench, Multi-SWE Bench, Multipl-E MBPP, SWE Multilingual. These five are description-based guard applications, not additions to the source-reviewed sample.
- Eligible classified complete repository histories: 473 → 419. Removed histories remain in raw storage; missing/unclassified/hosting repositories are excluded from direction aggregates, not assigned zero stars.
- Radar and Library canonical direction parity: all shared IDs match. Library and Radar chips now use the same direction names.
- 177 pipeline tests passed; static data, JavaScript syntax and site build validation passed. Browser visual verification was unavailable because local file browsing was blocked.
- General temporal/memory/GUI keyword rules still require a wider source review; this change applies verified corrections rather than claiming all 2,855 entries are audited.
