Analysis & methodology

Trend view: trailing four-week averages require four fully covered weeks. Raw observations remain visible as faint lines in the per-direction view. Smoothing reduces weekly noise; it does not establish a persistent or significant trend. Headline counts compare the latest four complete weeks with the preceding four, independently of the chart range. Share shifts use full-period counts and denominators.

Concentration: the contributor check selects the largest contributor in the latest four weeks and removes that same repository from the full displayed history. It is a sensitivity check, not a reason to discard the project. The 80% concentration flag and fewer-than-three-repos / fewer-than-five-stars sparsity flags are descriptive heuristics.

Release dates come from the recent local index, deduplicated by family. Coverage starts May 21, 2026; earlier periods are left blank. The first covered bin is partial. Older Library dates are not treated as complete historical coverage. Current direction labels are retrospective and can overlap.

When complete-history coverage is missing but matched snapshots exist, a separate chart shows net changes from the same repositories at all four endpoints (August 23, 30, September 6, 13). These values are not overlaid with star-creation histories and are not extended beyond their observed dates. RSI currently uses this fallback.

Star histories come from GitHub’s historical star-count endpoint, not snapshot differences. Only repositories whose entire paginated history was retrieved are included. Repositories returning 404 are excluded. Backfill coverage is shown above the charts. Failed and unrequested repositories do not become zeros. Star counts measure stars created in each period, not net changes after unstars.

All charts use identical complete-week bins, including longer ranges. Partial current weeks are excluded. Count uses a shared axis for all selected directions in each chart. Share divides each direction by the full covered release or repository population, not just selected directions. Overlapping shares do not sum to 100%. Zero-denominator shares are blank.

Dates returned by GitHub define weekly intervals; its boundaries are not guaranteed to match UTC. Repository history before creation contributes zero within this fixed, present-day sample; this is not a reconstruction of all repositories that existed historically.
